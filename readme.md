# SOFTWARE FJ

Sistema integral de gestión de clientes, servicios y reservas desarrollado en Python utilizando Programación Orientada a Objetos (POO).

## Descripción

Este proyecto fue desarrollado para gestionar clientes, servicios y reservas de una empresa llamada Software FJ.

El sistema permite:

- Registrar clientes
- Gestionar servicios
- Procesar reservas
- Validar datos
- Manejar excepciones
- Registrar eventos y errores en logs

El sistema funciona sin base de datos, utilizando objetos, listas y archivos de texto.

---

## Tecnologías utilizadas

- Python 3
- Programación Orientada a Objetos
- Git y GitHub
